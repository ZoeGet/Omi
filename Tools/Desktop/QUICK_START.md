# Omi Windows 使用说明

1. 完整解压压缩包。保留 `Omi.exe` 旁的 `omi-device` 文件夹，双击 `Omi.exe`。
2. 打开本机 Codex。在 Omi 首次使用向导中点击“重新检测监控”，核对列出的 Codex 程序；未检测到时可选择实际的 `Codex.exe`。
3. 点击“安装监控组件”。程序会先备份，再合并用户级 Hook；其他工具的 Hook 保留。能明确识别的旧 Omi Python 采集入口会迁移，无法确认归属的处理器会提示冲突并停止。
4. 在 Codex 中审查并信任新的 Omi Hook。CLI 可输入 `/hooks`；桌面版按其 Hook 审查提示操作。安装本身不会自动获得信任。
5. 让 Codex 执行一个普通操作，再回到 Omi 点击“重新检测监控”。看到“已收到真实事件，Codex 宿主关联正常”才代表接入通过。只收到消息事件时，可能仍需一次工具操作确认宿主。
6. 在首页“设备连接”选择 USB 或 Wi-Fi：USB 选择串口，Wi-Fi 选择已配对设备，再点击“连接设备”，连接成功后开启 Codex 监控。尚未配对、换网或待验证时，点击“配对与设备管理”处理。断联或租约结束关灯，语音优先。

不需要额外安装 Python、Rust 或开发工具。需要本机 Codex、WebView2，以及支持相应功能的设备固件。程序不会代装或登录 Codex。

电脑和设备更换 Wi-Fi 后，打开“无线配对”，在原来的“已保存设备”旁点击“在当前网络查找”。等待原设备身份验证成功、列表地址更新，再点击“无线连接”，不需要配对码。查找最多约一分钟；大型网络、网络隔离或设备被其他客户端占用时可能查找不到。也可点击“修改地址”，输入路由器设备列表中的新 IP，再点击“验证并保存地址”。验证失败会保留原配对记录。

配对与重新配对（需要升级配套固件和语音模型）：设备联网后说“老鼠狒狒”，听到确认音后说“开启配对模式”，屏幕显示新的六位码和当前 IP。电脑与设备处于可互通局域网，在“无线配对”填写屏幕地址、新码；首次配对点击“配对”，已有绑定、换电脑或丢失凭据时勾选“我确认重新配对”，点击“重新配对”。无需 USB，也不需要旧电脑凭据；成功后旧电脑的密钥失效。码限时 5 分钟、最多 5 次尝试，超时/锁定后可再次唤醒并说“开启配对模式”。普通重启不开窗，并可取消未完成的配对、保留旧绑定。窗口期间暂时断开旧无线连接；若提交后没有收到成功确认，先点击“验证连接”恢复，不要删除待确认记录。显示 `PAIR UNREADY` 表示设备未联网或服务未就绪，联网后再说一次。升级前固件不支持此入口，不能只更新上位机。

默认点击右上角 X 会隐藏到系统托盘，设备监控继续运行。单击托盘中的御坂美琴图标或右键选择“显示主窗口”恢复；图标也可能在 Windows 的隐藏图标区中。需要真正关闭时，右键托盘图标选择“退出软件”。设置页“关闭窗口时”可选择隐藏到系统托盘或退出软件，选择会保存；退出会先释放设备连接，但不卸载 Codex 采集组件。

采集组件会复制到 `%LOCALAPPDATA%/OmiPet/monitor-runtime/` 的固定目录。之后移动解压文件夹不影响已配置的采集器。请不要手动删除这个运行目录。

设置页可重新检测、修复/更新或卸载接入。Codex 更新导致程序路径变化时，重新选择实际程序并修复；Hook 定义变化后按 Codex 提示重新信任。卸载仅移除本程序管理的 Hook 和未修改的运行组件，保留其他 Hook、备份和历史状态；被占用或修改的组件会保留并提示。

备份位于 `%LOCALAPPDATA%/OmiPet/monitor-backups/`。监控元数据默认位于 `%LOCALAPPDATA%/OmiPet/codex-monitor-probe-v2/`，不保存提示词、工具参数和回复正文；这些本机数据不包含在分发包中。

没有新事件时，程序无法判断是未信任、尚未触发还是 Codex 尚未重新加载配置，请按步骤检查。组织策略禁止用户 Hook 时，需要管理员提供允许的接入方式。
