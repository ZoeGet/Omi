# OmiPet V1.0

OmiPet 的 Windows 设备控制中心，支持 USB / Wi-Fi 连接、本地灯光编辑和 Codex 任务状态监控。

## V1.0 更新（2026-10-20）

- 新增自动重连：记住上次成功连接的设备和方式；软件启动时尝试连接。运行中断连按 2/4/8/16/30 秒等待，最多重试五次，界面可取消；认证失败停止并提示人工处理。
- 手动断开或取消重连后不再自动连接，直到再次主动连接。原 USB 串口缺失、无线地址改变等情况需按提示手动选择或重新查找设备；不会自动配对或忽略设备身份验证。
- 灯光编辑显示未应用、等待确认、已确认或未确认；切换页面保留本次编辑。重连不重发灯光，恢复监控时重新判断任务来源有效性。
- 本次为同版本更新，旧用户请重新下载完整 ZIP，先退出旧程序，再解压到新文件夹运行。无需卸载或删除本机配对数据。

53 项界面、42 项桌面后台、133 项设备桥接测试及完整 Windows 构建、冻结后台模拟运行通过；真实设备拔插与断网恢复仍待验收。

## 下载哪个文件

在本页 **Assets** 中下载 **OmiPet-Windows-1.0.0.zip**。这是 Windows x64 便携包，无需安装 Python、Rust 或开发工具。GitHub 自动生成的 **Source code** 仅供开发，不是可运行的上位机。

## 第一次启动

1. 将 ZIP **完整解压**，打开其中的 `OmiPet` 文件夹，双击 **Omi.exe**。
2. 保留 exe 旁边完整的 **omi-device** 文件夹和许可文件，不要只发送或移动单独的 exe，也不要直接在压缩包中运行。
3. 需要 Microsoft Edge WebView2 Runtime；若系统缺失，请从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Runtime。
4. 准备支持对应功能的 Omi 设备。此压缩包不会自动烧录或升级设备固件。仅使用本地灯光不需要 Codex；任务监控需要已安装并运行的本机 Codex。

## USB 连接与调灯

1. 使用支持数据传输的 USB 线连接电脑和设备。
2. 打开“设备概览”，在“设备连接”中选择 **USB**，选择对应串口，点击“连接设备”。
3. 等界面确认已连接，选择“本地灯光”，进入“灯光与灯效”。
4. 从 **24 个常用色**中选色，或点击“自定义颜色”；设置亮度和灯效，最后点击 **应用灯光设置**。
5. 预览是动画模拟，以设备回执和实际灯光为准。彩虹使用独立色谱，不受单个颜色选择影响。

## Wi-Fi 配对与连接

1. 先让设备连接 Wi-Fi，并让电脑与设备处于可互通的局域网；访客网络、AP 隔离或防火墙可能阻止连接。
2. 对设备说 **“老鼠狒狒”**，听到提示音后说 **“开启配对模式”**。设备屏幕显示当前 IP 与六位配对码。
3. 打开“无线配对”，输入屏幕地址和新码，点击“配对”。配对码有效期 5 分钟，最多 5 次尝试；超时后重新用语音开启窗口。
4. 回“设备概览”，选择 **Wi-Fi** 和已保存设备，点击“连接设备”。之后正常连接不需要重复配对。
5. 换 Wi-Fi 后，在“已保存设备”中点击“重新查找设备”；必要时在“更多操作”中修改地址并验证。换电脑或丢失凭据时，使用“重新配对已有设备”，成功后旧电脑凭据会失效。

语音配对需要配套的无线固件和语音模型。屏幕显示 `PAIR UNREADY` 时先确认设备已联网且无线服务就绪。普通开机不会自动开启配对窗口。

## Codex 任务监控

1. 打开本机 Codex；在 Omi 首次向导或“设置”中点击“重新检测监控”，核对所选 Codex 程序，必要时选择实际的 `Codex.exe`。
2. 断开设备连接后，点击“安装监控组件”或修复/更新入口。程序会备份并合并自己的 Hook，保留其他工具的 Hook。
3. 在 Codex 中审查并信任 Omi Hook。CLI 可通过 `/hooks` 查看；桌面版按其提示操作。**安装组件不等于已经信任。**
4. 让 Codex 执行一次普通工具操作，再回 Omi 重新检测；提示“已收到真实事件，Codex 宿主关联正常”后，重新连接设备并开启 **Codex 监控**。
5. 默认灯色：运行红、等待操作黄、完成/空闲绿；来源异常和离线独立处理，绿色不一定代表任务已完成。可在“监控灯效”分别设置五种状态并保存到设备。
6. 配套固件支持设备屏幕最多显示 **4 个活动对话任务气泡**；超过四个显示额外数量。旧固件不一定具备此屏幕功能。

监控期间手动调灯被锁定；切回本地灯光后可编辑。语音优先，监控断联或租约到期关灯。任务监控依赖 Hook 事件，并非所有情况下都能独立确认聊天的真实运行状态。

## 常见问题与退出

- **没有串口：** 检查 USB 线是否支持数据，重新插拔并刷新串口列表；避免其他串口工具占用设备。
- **无线配对失败：** 核对 IP、新码、网络互通性；已有绑定但本机无凭据时使用“重新配对”，不要反复普通配对。
- **TASK SOURCE UNAVAILABLE：** 进入“连接诊断 → 连接与监控自检”，依次检查设备、组件、Hook 事件和当前任务数据；按提示修复、信任 Hook，并触发一次工具操作。有效空闲可显示 `NO ACTIVE TASKS`。
- **升级后监控异常：** 换用完整新包，并在设置里修复/更新已安装的监控组件；Hook 变化后按 Codex 提示重新信任。
- **关闭窗口后还在运行：** 默认点击 X 隐藏到托盘；右键托盘图标选择“退出软件”才是真正退出。设置中可以改变关闭行为。

详细说明见压缩包内 **QUICK_START.md**。个人配对凭据、Hook 安装记录和历史数据保存在本机，不随此安装包分发；不要把自己的本机数据目录上传到仓库或发给其他人。采集器不保存提示词、工具参数或回复正文；任务屏会使用本机标题索引生成标题位图。

## V1.0 内容与边界

- USB / Wi-Fi 连接、无线配对及重新寻址。
- 本地 24 色色板、自定义颜色、亮度及动画预览。
- Codex 监控、五状态灯效配置、连接诊断和系统托盘。
- 配套设备固件的四对话任务屏及断联恢复本地界面。

本发布包含 Windows 上位机便携包，不包含固件镜像。界面测试和 Windows 构建通过；不代表所有电脑、网络环境及设备长期运行均已验证。电池供电下曾有联网后灯带随机闪烁反馈，USB 下用户反馈正常，原因尚未定位；该硬件现象未在本版本中宣称修复。

第三方软件许可与图标来源说明随包提供，见 `THIRD_PARTY_NOTICES.md`、`DEPENDENCY_LICENSES.txt` 和 `APP_ICON_SOURCE.md`。
