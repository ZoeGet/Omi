# Omi V1.0.1

Windows x64 便携包更新（2026-10-22）。下载 **Omi-Windows-1.0.1.zip**，完整解压后运行 `Omi/Omi.exe`；保留相邻的 `omi-device` 文件夹。GitHub 的 Source code 是开发源码，不是可运行软件。

## 本版变化

- 启动时检查已配置的 Codex 程序路径；能唯一确认同一安装位置的新版本时，备份并更新 Omi Hook 路径，提示重新审查信任；情况不明确时提示手动处理。不会自动授予 Hook 信任。
- 修复启动回复携带的监控提示可能被丢弃的问题，确保需更新或确认信任的提示能够显示。
- 同一轮监控评估复用相同完整进程身份的查询，减少重复系统调用；每个聊天的事件证明独立校验，下轮重新查询，不延长状态有效期。
- 补齐包内项目许可、依赖许可与源码版本记录，并更新使用、隐私和验证边界说明。

## 从 V1.0 升级

1. 从托盘选择“退出软件”，再将新 ZIP 完整解压到新文件夹运行。不要仅替换一个 exe，也无需删除本机配对记录。
2. 若启动提示监控需要确认，按提示进入设置核对路径；需要时修复/更新监控组件，再在 Codex 中审查信任 Hook。
3. 触发一次普通工具操作后点击“重新检测监控”，确认真实事件与宿主关联正常。便携包更新不等于已安装的独立监控组件全部自动更新。

## 源码和验证边界

本包对应 [`v1.0.1` 标签](https://github.com/ZoeGet/Omi/tree/v1.0.1)，完整提交号见包内 `SOURCE_VERSION.txt`，ZIP SHA256 见 GitHub Release。原 V1.0 标签及发布记录保留。

相关源码已通过 56 项前端、50 项桌面后台、85 项监控和 133 项通信桥测试。Windows 构建、许可收集、包文件一致性与冻结后台模拟流程均单独验证；具体发布包结果见 Release。未把模拟或编译通过当作真实 USB/Wi-Fi、托盘交互、Codex 升级信任流程及长期运行的完整验收。

发布仅包含 Windows 上位机，不包含固件镜像，也不会刷写设备。仓库中的 AHT20 恢复修复与默认关闭的分步采样属于固件源码改进，不会随本软件自动安装到设备。保留现有灯光、配对与监控状态规则；来源异常显示绿色仍不代表任务已完成。

项目许可及第三方来源见随包 `LICENSE.txt`、`THIRD_PARTY_NOTICES.md`、`DEPENDENCY_LICENSES.txt` 与 `APP_ICON_SOURCE.md`。用户数据、配对凭据和原始日志不随包分发。
