# Omi application icon

The user selected Misaka Mikoto as the application avatar. The image reference is the official anime portrait at https://toaru-project.com/index_3/chara/mikoto.html (image: https://toaru-project.com/index_3/core_sys/images/main/chara/chara_img12f.png).

The built-in imagegen tool prepared a square head-and-shoulders avatar from that reference. Character and reference-art rights remain with their original rightsholders; this asset is not represented as MIT-licensed artwork. No third-party fan artwork was used.

Prompt: Preserve Misaka Mikoto's character identity, brown bob, flower hairclip, brown eyes, expression and Tokiwadai uniform from the official reference. Close, centered head-and-shoulders framing for a Windows app icon; pale sky-blue background; clear at 32px; no text, logo, extra character, device or lightning. Final refinement: fill the entire square background opaquely with pale sky blue, remove every transparent gap and preserve the character. No transparent corners, vignette or irregular cutouts.

Tauri's official `icon` command converted the result to `256x256.png` and a multi-resolution `icon.ico`. The PNG is shared by the sidebar and browser favicon; the ICO supplies the Windows executable/titlebar icon.
